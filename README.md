# GDZ Telegram Bot

Бот ищет задания в выбранной книге на `4book.org` и присылает решение картинками.

По умолчанию используется книга:

`https://4book.org/gdz-reshebniki-ukraina/10-klas/reshebnik-algebra-10-klas-merzlyak-2018-gdz`

Примеры запросов:

- `29.1`
- `30.1`
- `30.3-30.10`
- `2.12 (1-2)`

Можно также отправить полную ссылку на страницу `4book.org`.

## Файлы

- `bot.py` - Telegram-бот
- `scraper.py` - парсер `4book.org`
- `.env.example` - пример переменных окружения
- `render.yaml` - готовый конфиг для Render
- `Procfile` - запуск для платформ вроде Railway

## Локальный запуск

1. Установить Python 3.11+.
2. Поставить зависимости:

```bash
pip install -r requirements.txt
```

3. Создать `.env` и прописать токен:

```env
BOT_TOKEN=123456:ABCDEF
BOOK_URL=https://4book.org/gdz-reshebniki-ukraina/10-klas/reshebnik-algebra-10-klas-merzlyak-2018-gdz
```

4. Запустить:

```bash
python bot.py
```

## Хостинг 24/7

Проект уже подготовлен для деплоя как фонового воркера.

### Render

1. Залить проект в GitHub.
2. Создать новый сервис из репозитория.
3. Render подхватит `render.yaml`.
4. В переменных окружения указать `BOT_TOKEN`.
5. После деплоя бот будет работать как `worker`, даже когда компьютер выключен.

### Railway

1. Залить проект в GitHub.
2. Создать проект из репозитория.
3. Указать переменные `BOT_TOKEN` и при необходимости `BOOK_URL`.
4. Railway может запускать процесс из `Procfile`.

## Команды

- `/start` - подсказка
- `/reload` - заново собрать индекс книги

## Важно

- `.env` не загружай в публичный репозиторий.
- Если токен уже где-то светился, лучше перевыпустить его через `@BotFather`.
- Бот зависит от структуры сайта `4book.org`, поэтому при изменениях сайта парсер может потребовать обновления.
